# Awesome-Dynamic-Page-Layout-Management

# Top Dynamic Page Layout Management Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Visual Page Building, Component Composition & Content Modeling*  
**Last updated: March 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Dynamic Page Layout Management**. These tools enable teams to compose pages visually from reusable components, manage structured content models, and deliver dynamic experiences across web and mobile channels.

**Examples** include Salesforce Dynamic Pages, Contentful Studio, Builder.io, Plasmic, Prismic Slices, Sanity Studio, Webflow Enterprise, Storyblok Visual Editor, Strapi, and ButterCMS (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, visual editing, and open content modeling — ideal for developers, marketers, and organizations seeking transparent, vendor-independent page layout solutions.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[Salesforce Dynamic Pages](https://www.salesforce.com/)**  
  Lightning Experience feature for building dynamic record pages with conditional field visibility based on record data, device, or user permissions. Enables admins to create responsive interfaces without code and eliminate multiple page layouts .

- **[Contentful Studio](https://www.contentful.com/)**  
  Visual workspace added to Contentful in 2025 for building pages without engineering bottlenecks. Features deep integration with Contentful's headless CMS ecosystem, enterprise governance, and multi-space support .

- **[Builder.io](https://www.builder.io/)**  
  Visual development platform for editing over existing codebases. Features Visual Copilot 2.0 for Figma-to-code generation, A/B testing, and support for React, Next.js, Vue, Angular, and Svelte .

- **[Plasmic](https://www.plasmic.app/)**  
  Visual builder and headless CMS for front-end development. Designers and developers compose pages in Plasmic Studio, then ship via Headless API (Loader) or Codegen pipeline. Open-source core with MIT license .

- **[Prismic Slices](https://prismic.io/)**  
  Component-based content modeling where developers define reusable slices (Hero, CTA, Quote) and content writers compose pages by stacking slices. Slice Machine generates code components automatically .

- **[Sanity Studio](https://www.sanity.io/)**  
  Open-source, real-time collaborative content workbench where developers define models in JavaScript. Features granular patch-based mutations for conflict-free collaboration and extensive React customization .

- **[Webflow Enterprise](https://webflow.com/)**  
  Visual development platform with next-gen CMS architecture. Features multi-level nesting (up to three layers), 40 Collection lists per page, and 1M+ CMS items per site for AEO-ready content experiences .

- **[Storyblok Visual Editor](https://www.storyblok.com/)**  
  Headless CMS with inline visual editing. Features blocks (Content type, Nestable, Universal) for flexible page composition, presets, and real-time preview. Editors arrange blocks directly on the live page .

- **[Strapi](https://strapi.io/)**  
  Leading open-source headless CMS with Dynamic Zones for flexible page composition. Developers define components (Hero, Features, Quote) and content editors arrange them in approved zones without code changes .

- **[ButterCMS](https://buttercms.com/)**  
  Marketing-first headless CMS with Component Picker for drag-and-drop page building. Reusable components (Hero, Features, Testimonials) can be added in any order, with Component Library management for cross-page reuse .

## Open-Source GitHub Projects

- **[Plasmic](https://github.com/plasmicapp/plasmic)**  
  Open-source visual builder and headless CMS (MIT for core). Features visual page composition, component registration from host codebase, Headless API for runtime fetching, Codegen for React/Next.js/Gatsby source generation, CMS API for structured content, and CLI for code sync. Self-hostable via Docker with integrations for any CMS, ecommerce, or hosting provider .

- **[Puck](https://github.com/measuredco/puck)**  
  Open-source visual editor for React (MIT) with 12.6K+ GitHub stars. Features drag-and-drop page building inside your own application, React Server Components support, and zero vendor lock-in. No SaaS required — you own the editor, data, and rendering .

- **[GrapesJS](https://github.com/GrapesJS/grapesjs)**  
  Open-source web builder framework (BSD-3-Clause) with 26K+ GitHub stars. Features drag-and-drop HTML/CSS generation, component blocks, style manager, and code export. Used by SaaS products embedding visual builders for email, landing pages, or documents .

- **[TinaCMS](https://github.com/tinacms/tinacms)**  
  Open-source, Git-backed CMS (Apache-2.0) with visual editing for Next.js. Features inline editing on live site, Markdown/MDX content, and full version control via Git. Content stored as files in your repository .

- **[Sanity Studio](https://github.com/sanity-io/sanity)**  
  Open-source React-based content workbench (MIT). Developers define schemas in JavaScript, Studio auto-generates editing interface. Features real-time collaboration with granular patches, extensive customization, and structured content Lake backend .

- **[Strapi](https://github.com/strapi/strapi)**  
  Leading open-source headless CMS (MIT) with 65K+ GitHub stars. Features Dynamic Zones for flexible page composition, component library approach with guardrails, REST and GraphQL APIs, and role-based access control. Developers build components, editors compose pages .

- **[Directus](https://github.com/directus/directus)**  
  Open-source data platform (BUSL-1.1) wrapping any SQL database with admin app and APIs. Features granular permissions, workflows, and extensibility. Can serve as backend for custom page layout management.

- **[Payload CMS](https://github.com/payloadcms/payload)**  
  Open-source headless CMS and application framework (MIT). Built with TypeScript, Express, and MongoDB/Postgres. Features customizable admin UI, access control, and local API for page composition.

- **[KeystoneJS](https://github.com/keystonejs/keystone)**  
  Open-source headless CMS and GraphQL API framework (MIT). Features schema-driven development, customizable admin UI, and database adapters for PostgreSQL, MySQL, and SQLite.

- **[Wagtail](https://github.com/wagtail/wagtail)**  
  Open-source CMS (BSD-3-Clause) built on Django with 18K+ GitHub stars. Features StreamField editor for flexible page composition, image management, and excellent editorial workflows.

### Additional Strong Open-Source Options

- **[Vue Form Making](https://github.com/gavinzhulei/vue-form-making)** — Visual form designer for Vue.js with code generation.
- **[form-create](https://github.com/xaboy/form-create)** — JSON-driven form generator and low-code builder (MIT).
- **[Builder.io Open Source SDKs](https://github.com/BuilderIO)** — Open-source React, Next.js, and Vue SDKs for Builder.io integration.
- **[Prismic Slice Machine](https://github.com/prismicio/slice-machine)** — Open-source tool for creating and managing Prismic slices.
- **[Sanity Studio Plugins](https://github.com/sanity-io)** — Community plugins for extending Sanity Studio functionality.
- Community **n8n** workflows for content orchestration and page deployment automation.

**Frameworks for building custom systems**: Combine **Puck** or **GrapesJS** as the visual editor with **Strapi** or **Directus** for content modeling and API delivery, **Plasmic** for code-connected component composition, and **PostgreSQL** for persistence — creating a fully self-hosted, enterprise-grade dynamic page layout platform.
